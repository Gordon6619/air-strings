# 空中弦樂器 Air Strings

[開啟線上演奏版](https://gordon6619.github.io/air-strings/)

推送至 main 時，GitHub Actions 會執行測試，下載並校驗攝影機辨識資源，再將 public 發布至 GitHub Pages。線上版直接從本站載入手部模型。

以固定攝影機追蹤雙手，在鏡像畫面中建立及撥奏最多八條弦。程式附自製的 Web Audio 合成音色、可復原的場景編輯、滑鼠及數字鍵操作。攝影機只在使用者選擇啟動後開啟，影像在本機處理。

## 開始試奏

**直接試用**　用桌面 Edge 或 Chrome 開啟 Air-Strings.html。點「滑鼠演奏」，將游標移過畫面上的五條示範弦，或按鍵盤 1–5。拖曳空白處可增添弦，拖曳弦端可調音。琴弦區顯示音名，點音名可試音。滑鼠模式的圖形、操作和音色全部內建。

**用攝影機**　Windows 桌面可雙擊 Start-Air-Strings.cmd，在本機網址按「啟動攝影機」。本機伺服器需要 Node.js 22.13 以上；程式已編譯，啟動時無須安裝 npm 套件。首次使用需能下載鎖定的 npm 套件及 Google 的模型，完成後允許攝影機。若使用單檔版，瀏覽器會嘗試將通過驗證的模型存進 IndexedDB，快取依瀏覽器及檔案位置而異。

**手勢**　先張開手掌穩定入鏡，兩手在空白處一起捏合並拉開，放開一手即固定。兩手皆放開後再做下一條。伸出食指穿過弦線發聲；從端點位置捏合則可移動端點。調音後下一次撥弦使用新頻率。首度進攝影機會從空白畫布開始。若已編輯示範場景，則保留編輯結果。

**離線展場**　在可連網的電腦執行 Install-Camera.cmd，確認顯示 Camera ready。將含 public/vendor 的完整資料夾帶到裝有 Node.js 的展機，執行 Start-Air-Strings.cmd。展前斷網重開，以實際相機與喇叭驗收。若 IT 分開提供兩個原始檔，可使用下列指令在離線電腦安裝，安裝器會比對雜湊。

```powershell
node scripts/install-camera.mjs "C:\kits\tasks-vision-0.10.21.tgz" "C:\kits\hand_landmarker.task"
```

模型、執行檔版本與官方下載網址列於 camera-assets.lock.json。此發行包未內附第三方二進位資產。下載失敗時可立即使用滑鼠模式或重試。單檔模式如受企業政策限制，請改用本機伺服器版。切換到其他分頁會停止演奏並釋放攝影機，回來再按啟動即可。

## 維護與驗收

```powershell
npm test
npm run build
npm start
```

修改 src/core.ts、src/gesture.ts 或 public 下的原始模組後，執行 build 會重建 public/core.js、public/gesture.js 與單檔版。測試使用 Node 內建工具。手勢設定集中在 core.ts 的 config v1。公開部署時，先安裝模型，再將 public 整個目錄部署至 HTTPS 靜態站。本機服務預設綁定 127.0.0.1，不對區域網路開放。

|檔案|用途|
|---|---|
|src/core.ts|正規化影像座標、音高、碰撞事件、場景格式、編輯紀錄|
|src/gesture.ts|跨影格手掌配對、捏合計時、建弦、彈奏及失追恢復|
|public/camera.js、tracking-worker.js|攝影機生命週期、最新影格優先、雙手本地推論|
|public/audio.js|十六聲部撥弦合成、力度、淡出及輸出控制|
|public/app.js、index.html、style.css|演奏畫布、引導、場景及診斷面板|
|test/|合成手勢樣本、攝影機生命週期測試及單檔入口整合測試|

「場景與診斷」可匯出或匯入 JSON，也可下載最近的演奏事件與執行統計。場景檔記錄弦端點、長寬比、調音方式及參考音高。匯入格式錯誤時保留原場景。「影格至派送」是軟體事件耗時，實體指尖越線到喇叭出聲的延遲須用外部設備量測。
